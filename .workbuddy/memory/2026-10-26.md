# 2026-10-26

## 项目上下文
- 本仓库是 **Wrye Bash**（Bethesda 引擎 MOD 管理工具，GPLv3），源码在 `Mopy/bash`，约 13.5 万行 Python。
- 基于 `master` 创建了 `mcp-dev` 分支并切过去（用于后续 MCP 相关开发）。当前本地分支：mcp-dev。

## 产出
- 新建 `项目介绍.md`：详细项目导览，开头按用户本地 **uv 环境** 写启动方式（`uv venv --python 3.11` + `uv pip install -r requirements.txt` + `uv run python "Mopy/Wrye Bash Launcher.pyw"`）。
- 关键信息：依赖 Python 3.11 64 位、wxPython 4.2.5；GUI 基于 wxPython，`gui/` 是其封装层（非自研框架）；`game/` 是最大的适配层（~5.2 万行）；`bush.py` 负责游戏探测。
