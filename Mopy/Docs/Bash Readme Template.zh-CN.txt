=== 自动转换功能
要触发 Wrye Bash 的自动转换功能……
* 在 BASH 的文档浏览器中选择该文件的文本版本。
* 文本文件的第一行必须如下所示 <code>= Title ====#</code>请特别注意。 <code>= </code> 在开始时以及单次使用时 <code>#</code> 最后的角色！
* 在文档浏览器中查看该文件。如果 BASH 发现 HTML 文件的版本比文本文件旧，它就会自动进行转换。请注意，这意味着您可以在外部文本编辑器中编辑文本文件，依然能够获得自动转换功能。

=== CSS
{{CSS:wtxt_teal.css}}
可以通过在 CSS 标签中指定 CSS 文件来替换默认样式。请注意：
* CSS 文件必须单独占一行。
* CSS文件未被链接，而是在编译时直接被包含进来。 
* CSS 文件中不得包含任何 HTML 标签（甚至连注释也不行）。
* 不允许指定目录路径。 
* CSS文件必须位于与源文档相同的目录中，或位于其他相应目录中。 <code>Morrowind\Data Files\Docs</code> 目录。如果两个目录中都存在该文件，则会使用当前目录中的版本。
* 如果未指定 CSS 文件，则会使用默认的沙色风格集。
* 您可以提供自己的 CSS 文件，也可以使用现成的文件。如果使用自备文件，请为其指定唯一的名称，以避免覆盖其他模组制作者的 CSS 文件。附带的 CSS 文件包括：
  * wtxt_teal.css
* 将 CSS 标签放在文档末尾是个不错的选择。
